# Панель Usage для DeepSeek Harness

[English](README.md) | **Русский** | [Українська](README.uk.md)

**DSH 0.2.2-rc.1**, плагин **0.1.1**. Отдельное расширение под контролем пользователя; оно не изменяет архив приложения, OAuth-плагин, настройки моделей, хранилище учётных данных или биллинг.

## Интерфейс

- **Usage** в панели редактора сообщения открывает компактный отчёт по текущему сеансу и последнему вызову. Встроенные виджеты токенов всего журнала и контекста остаются без изменений. Добавленный индикатор показывает только стоимость, не дублируя встроенный счётчик токенов.
- **Usage** на боковой панели открывает отдельную страницу с вкладками Sessions / Models / Days, фильтрами дат по местному календарю, графиком дневного расхода токенов с ограниченным числом точек и постепенной загрузкой истории. Кнопка **Close** справа вверху возвращает к переписке через штатный сервис компоновки, не закрывая и не переключая текущий сеанс.
- Отчёты учитывают **только собственные вызовы сеанса с зафиксированным результатом**. Скопированная при ответвлении или инициализации история исключается: исходный расход относится к сеансу-предку. Заполненность контекста — отдельная величина, а не накопленный расход токенов.
- История загружается по пять сеансов. Итоги и графики описывают **загруженные сеансы**, а не весь аккаунт. Refresh создаёт новый снимок; после истечения срока действия курсора требуется Refresh. Сам штатный список заголовков сеансов не разбит на страницы.
- Группировка по дням использует указанный часовой пояс IANA и сохранённые отметки времени фиксации результатов, а не дату создания сеанса или счёта провайдера. Отсутствующие даты и данные расхода, недоступные сеансы и усечение истории обозначаются явно.

## Что означают показатели

Input — входные токены без учёта кэша. Чтение и запись кэша учитываются отдельно, без пересечения; токены рассуждений уже входят в output. Отсутствующие значения остаются неизвестными, а не превращаются в нули. Достоверное общее число токенов от провайдера может подтвердить нулевой расход в отсутствующей категории кэша; иначе значение остаётся неизвестным.

Итоговые данные расхода заменяют более ранние данные той же попытки. Повторный запрос учитывается как отдельная попытка. Более поздняя неполная запись результата не стирает уже полученные данные: известная промежуточная сумма сохраняется с пометкой о неполноте. Правки отображаемой истории и уплотнение контекста не отменяют предыдущий расход. Учитываются только сохранённые результаты сообщений ассистента и попыток; незаписанные вспомогательные запросы и начисления на стороне провайдера не выдумываются.

Значения в долларах — **оценки эквивалентной стоимости API по каталогу, а не фактически списанные деньги, счёт, остаток средств, право на подписку или оставшаяся квота**. Используется публичный каталог pi-ai **1.3.0**, поставляемый с этой версией DSH, точные ключи провайдера и модели и пороги тарифных уровней для каждого вызова. Исторические изменения тарифов, переопределения конечных точек API, скидки и реальные коммерческие условия профиля неизвестны.

Известные маршруты, которые могут работать по подписке или токен-плану, консервативно исключаются из долларовых оценок. **Subscription / not calculated** — правило отображения, а не доказательство того, что исторический запрос использовал OAuth: общие сохранённые заголовки не содержат тип аутентификации. В частности, токены ChatGPT/Codex не превращаются в вымышленную плату за подписку. Неизвестные псевдонимы и модели, искусственные полностью нулевые цены, отсутствующие счётчики и неоднозначная длительность хранения при записи кэша остаются без оценки. Итоги с оценкой лишь части вызовов помечаются как неполные.

Единица стоимости зафиксирована в [документации моделей pi 1.3.0](https://github.com/earendil-works/pi/blob/v1.3.0/packages/coding-agent/docs/rpc-commands.md): доллары США за миллион токенов.

## Конфиденциальность и контроль доступа

Хост регистрирует только два POST-обработчика с точными путями на **существующем транспортном слое Connection в DSH с аутентификацией владельца**. Не создаются отдельный сервер или слушатель, разрешения, wildcard-маршрут Gateway или механизм разрешения учётных данных. Штатная проверка доступа транспортного слоя выполняется до этих обработчиков; дополнительно требуются JSON, нестандартный заголовок `X-DSH-Usage: 1`, тело размером не более 4 КиБ и проверки Origin/Host. Штатный мост Desktop вправе не передавать Origin. Идентификаторы сеансов, похожие на пути к файлам, отклоняются.

История читается локально, только для чтения, через `sessionQuery.observeSession` с `projectionMode: 'none'`; штатная реализация сама читает и проверяет сохранённые журналы. Неактивный Agent не подключается и не возобновляется. Расширение выбирает только счётчики расхода, сохранённые идентификаторы маршрутов и отметки времени событий, освобождая каждую аренду наблюдения. Оно никогда не возвращает тексты сообщений, потоки, заголовки, инструменты, cwd, названия, ссылки на учётные данные, пути или исходные исключения. Хранилище учётных данных, ключи окружения и API обнаружения моделей не просматриваются.

Очищенные агрегаты и снимки с непрозрачными курсорами ограничены по объёму, хранятся в памяти и привязаны к профилю и идентичности сервисов. Прокси Cordis сравниваются по канонической идентичности, а вызовы продолжают проходить через трассируемые прокси. Расширение не перезаписывает журналы сеансов и кэши проекций. Ограничение порции пятью сеансами не превращает штатную загрузку журналов неактивных сеансов в постраничное чтение по байтам. При достижении лимитов событий, вызовов или записей потоков на сеанс отчёт явно помечается как неполный.

## Проверка и сборка

Используйте Node.js 22 или новее. Устанавливать зависимости для работы или разработки не требуется.

```sh
npm run build
npm run check
npm test
npm run test:native
```

Детерминированные тесты покрывают учёт расхода, повторные попытки и ответвления, неизвестные значения, цены и границы тарифных уровней, идентичность профилей и прокси, отмену и освобождение ресурсов, курсорную пагинацию, часовые пояса, жизненный цикл контроллеров интерфейса и формат запросов к транспортному слою владельца. Фикстуры компонентов и контроллеров — **не проверка в настоящем браузере**.

Необязательная команда `test:native` требует macOS и установленного Desktop-приложения соответствующей версии. CI выполняет только переносимые проверки сборки, синтаксиса и детерминированные тесты.

Нативный smoke-тест использует реально установленные Cordis, SessionStore, SessionQuery, плагин-файбер и проверку владельца Connection в новом изолированном Context в памяти с искусственной браузерной аутентификацией. Он не открывает сокеты, не читает профиль, журналы или учётные данные пользователя и не выполняет запросы к моделям или сети. Искусственные фикстуры проверяют контракт интеграции, а не отображение в настоящем браузере или фактический биллинг аккаунта.

Готовый браузерный артефакт генерируется из собственных исходников и автономной логики вычислений. Он загружает только React, предоставленный хостом, без импорта внутренних значений клиентских пакетов и без второго рендерера. Не нужны фоновый процесс пересборки или отдельный сервер GUI. Другая версия DSH требует повторной проверки контрактов, а не исключения из проверки совместимости.

Чтобы пересоздать снимок фактических цен, запустите генератор через встроенный Electron в режиме Node или передайте ему корень извлечённого **публичного кода SDK**. Он разбирает только JSON-каталоги провайдеров, не импортирует обнаружение моделей или аутентификацию и не читает настройки.

## Установка и удаление

Клонируйте репозиторий в постоянный каталог: установленный плагин ссылается на эту рабочую копию. Для использования готового браузерного артефакта из репозитория не нужны npm install или сборка. Используйте встроенный CLI, соответствующий запущенному приложению, а не устаревшую глобально установленную команду `dsh`:

```sh
git clone https://github.com/rooty/dsh-usage-dashboard.git
cd dsh-usage-dashboard
"/Applications/DeepSeek Harness.app/Contents/Resources/runtime/cli/bin/dsh" plugin --profile desktop add "$PWD"
```

Полностью закройте DSH через **⌘Q**, откройте его снова и проверьте индикатор Usage в редакторе сообщения и страницу Usage на боковой панели существующего GUI. Выход из аккаунта, повторная авторизация, API-ключ или смена провайдера не нужны. До этой ручной проверки интерфейс следует считать предварительной версией с проверенной сборкой, а не подтверждённо работающим GUI.

Чтобы убрать выбор плагина, не удаляя переписку и учётные данные:

```sh
"/Applications/DeepSeek Harness.app/Contents/Resources/runtime/cli/bin/dsh" plugin --profile desktop remove @local/dsh-usage-dashboard
```

## Известные ограничения

- Совместимость зафиксирована для DSH **0.2.2-rc.1**; другие версии требуют повторной проверки.
- Закрытый индикатор стоимости в редакторе пока не подписан на обновления результатов вызовов. Откройте Usage или нажмите Refresh для загрузки актуальных значений; пока всплывающая панель открыта, она обновляется каждые десять секунд.
- Сборки, фикстуры и нативные smoke-тесты не подтверждают отображение в настоящем браузере или фактический биллинг аккаунта.
